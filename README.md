# PrepFront

**Открыть тренажёр:** [grinushka.github.io/interview-study](https://grinushka.github.io/interview-study/)

Сайт публичный, открывается на компьютере и телефоне. Новые push в ветку `main` автоматически обновляют GitHub Pages.

Локально открой **index.html** двойным щелчком. Установка и сервер не нужны. Сайт также готов к публикации на GitHub Pages: HTML, JavaScript и CSS не требуют сборки на сервере.

На телефоне открывай опубликованный адрес сайта в браузере. Прогресс хранится отдельно в каждом браузере/устройстве; для переноса используй экспорт и импорт JSON, автоматической синхронизации нет. GitHub Pages отдаёт файлы как статический сайт; `.nojekyll` отключает обработку Jekyll.

15 тематических уроков с объяснениями, вопросы, повторение и смешанная проверка знаний. В каждом из 84 разделов: исходная задача, объяснение по шагам, конкретный пример и краткий итог темы. Код сопровождается разбором там, где он помогает понять теорию. Списки терминов остаются отдельным справочником. Базы данных и исключённые инструменты не входят в программу. IndexedDB остаётся только как браузерный API хранения.

## Как заниматься

1. На странице урока прочитай объяснение, проследи шаги и разбери пример. Короткий итог в конце помогает повторить уже понятую тему. Затем отметь раздел прочитанным.
2. Переключись на «Вспомнить и объяснить». Можно ответить вслух или написать ответ.
3. Раскрой структурированный образец и поставь самооценку. У каждого дополнительного вопроса есть свой скрытый ответ.
4. В конце урока возьми три вопроса из других изученных уроков. Сначала, пока других нет, вопросы берутся из текущего.
5. В «Повторении» выбери сложные вопросы или любую тему. «Проверка знаний» даёт десять вопросов из разных уроков.

Списки изучаются целиком и по элементам. Для открытых наборов (например, хуков и Utility Types) прямо обозначен учебный состав. Свободные ответы оценивает сама учащаяся, не AI. Код служит разбору теории; произвольный код не исполняется.

## Поиск

Поле на главной странице и кнопка поиска вверху любой страницы ищут по всему учебному материалу. `Ctrl+K` / `Cmd+K` открывает отдельное окно; на телефоне это полноэкранный поиск. Доступны фильтры «Теория», «Вопросы», «Примеры». Совпадения группируются по темам, фрагменты объяснений подсвечиваются. Ссылки ведут прямо к разделу, примеру или упражнению. Ответы на вопросы в выдаче не раскрываются. Поддерживаются основные русские и английские названия. Поиск работает локально и не отправляет запросы в интернет.

## Сохранение прогресса

Написанные ответы, самооценки, отметки чтения, порядок, пары и незавершённый раунд сохраняются в браузере. Отметка «Прочитано» не означает «Могу объяснить».

Раздел «Прогресс» экспортирует и импортирует JSON. Импорт объединяет записи; совпадающие записи из файла заменяют текущие. Экспортируй прогресс перед переносом папки, очисткой browser data или сменой браузера. Если браузер блокирует localStorage, появится сообщение; занятие и экспорт всё равно доступны в текущей вкладке.

Для надёжного хранения при file:// отдельные HTML-входы открывают соответствующий маршрут в общем index.html. Каждый lesson-XX.html также содержит статическую теорию и читается без JavaScript. Все зависимости локальны, fetch и ES modules не используются.

## Источники и редактирование

Основной материал — страница Notion «questions». Пробелы дополнены документацией MDN, React, TypeScript и других авторов технологий. Уточнения к заметкам выделены внутри уроков. Источники открываются по ссылкам каждого раздела. 11 ноября 2026 добавлены подробные объяснения и примеры ко всем разделам.

«Реестр тем» связывает исходные заголовки и вопросы чата с упражнениями. Машиночитаемые данные: coverage.json. Исключённые темы помечены отдельно.

Основное содержание и генератор страниц находятся в build.py, развёрнутые объяснения — в explanations.py, обновления по Gen notes — в revision_content.py, поведение — в app.js, оформление — в style.css. После изменения содержания выполнить:

```powershell
python build.py
```

Проверки (для browser checks нужен Python-пакет Playwright и Chrome):

```powershell
node --check app.js
python check.py
python check_search.py
python check_revision.py
python check_sources.py
```

Проверяются реальные file://-переходы, все уроки, поиск, сохранение ответов, самооценка, порядок, пары, повторение, завершение и продолжение проверки знаний, импорт/экспорт, некорректный импорт, блокировка localStorage и мобильная ширина. Скриншоты preview-*.png создаются проверкой и не содержат настоящих ответов пользователя.

## Изменения по Gen notes

Все 15 замечаний связаны с разделами в [реестре изменений](REVISION.md). 351 вопрос используют структурированные ответы; уточнения раскрываются независимо. Короткие ответы не заменяют объяснения, а дают порядок устного ответа. Новые темы находятся в уроке 4. ID прежних вопросов и формат JSON прогресса сохранены.

## Семь задач на callbacks и таймеры

В уроке «Асинхронность» есть раздел «Практика: callbacks и таймеры». Сначала напиши небольшой фрагмент в поле решения; затем раскрой образец, временную шкалу и разбор ошибки. Черновик сохраняется вместе с прогрессом. Код в браузере тренажёра не запускается. Проверка решений: `python check_timer_practice.py`.

## Задачник

Отдельная страница `tasks.html` доступна через пункт «Задачник». 54 задачи из всех 15 уроков: написать код, предсказать результат, найти ошибку, выбрать решение, восстановить порядок, сопоставить пары. Есть фильтры темы/формата/самооценки, поиск по условию, случайная задача и подборка из пяти разных тем. Ответы и уточнения скрыты до раскрытия. ID общие с уроками: прогресс и черновики не дублируются. Проверка: `python check_taskbook.py`.
